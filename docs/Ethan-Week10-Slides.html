CV Model — status

rebuilt around AR tags — we went back to them after reading last semester's thesis
Problems with the old vision stack
  • Errors cascaded
    • A piece placed 2–3 cm off became hard to pick up next turn, and got worse every move
  • Four stacked dependencies to locate one tag
    • camera intrinsics → extrinsics → TF tree → tag pose. Each one a failure point
  • 2–3 cm localisation error
    • Our cells are 37.5 mm — that's most of a square
  • Colour detection can't tell two same-coloured pieces apart, and burns Pi cycles
What we built
  • AR tag = piece identity
    • Works for any game and any piece shape — this is what makes generalising possible
  • 4 corner markers → homography
    • No intrinsics, no TF tree, no calibration step — the whole chain above is gone
    • 2D throughout, so no depth estimate — that was the main source of the 2–3 cm error
  • Pick where the piece is, place where it should be
    • Stops errors compounding, without drifting off the ideal grid
  • Temporal voting (5 frames) — a hand over the board can't move the state

Not done: never run against a real camera yet. Corner marker IDs currently clash with the piece tag IDs, irregular boards still aren't supported, and game-state validation isn't written.
